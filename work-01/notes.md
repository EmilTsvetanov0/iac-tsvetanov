## Журнал ручных действий (практическая работа №1, вариант 02)

1. Открыл Compute Cloud -> Виртуальные машины -> Создать виртуальную машину
2. Написал имя машины: tsvetanov-02-web-manual
3. Добавил метку created-by:console
4. Выставвил образ ubuntu-24.04
5. Выбрал зону доступности ru-central1-b
6. Выбрал загрузочный диск HDD на 20 ГБ
7. Настроил свою конфигурацию. Платформа: Intel Ice Lake, vCPU: 2, Гарантированная доля vCPU: 20%, RAM: 2 ГБ, Прерываемая: True
8. Подсеть: Default, публичный адрес: Автоматически
9. Способ доступа: ssh и логин: student
10. Открыл и вручную скопировал публичный ключ на сайт
11. Отключил резервное копирование
12. Нажал "Создать ВМ"
13. Скопировал публичный IP-адрес ВМ и подключился к виртуальной машине по SSH
14. Выполнил sudo apt update
15. Установил nginx через sudo apt install -y nginx и проверил через systemctl status nginx
16. Изменил стандартную надпись на cloudlab и имя хоста
17. Проверил изменённую страницу в браузере
18. Завершил SSH-сеанс
